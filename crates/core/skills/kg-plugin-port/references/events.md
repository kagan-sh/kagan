# Events and examples

`thread.<type>` may be any live kind: `created`, `started`, `exited`, `stopped`, `idle`, `waiting`, `failed`, `archived`, `unarchived`, `deleted`, `answered`, `notice`, `turn.started`, `turn.ended`, `message`, `tool.started`, and `tool.ended`. Any other event name is refused. The other kinds an old log may hold — `tool`, `restore.failed`, `snapshot.failed`, `reconnecting`, `opened`, `rewound`, `file.changed`, `file.read` and `file.predicted` — still load but cannot be waited on or subscribed to. kagan writes `created`, `started`, `exited`, `stopped`, `idle`, `waiting`, `failed`, `archived`, `unarchived`, `deleted`, `answered`, `notice`, `turn.started`, `turn.ended`, and `message` when `threads.send` or `kg thread send` submits a line (`data.role` is `user`). It also writes `tool.started` (`data: { id, name }`) and `tool.ended` (`data: { id, status: "ok" | "error" }`) around each agent tool call kagan serves, sharing one id and no input or reply text. The screen is not parsed into messages. A confirmed quit writes `stopped` and `idle` and does not write `turn.ended`. A crash while a turn is open writes `failed` and does not write `turn.ended`. A working mark that is not the first character of the title, including U+23F3 after a plain prefix, does not open a turn.

A panel may set `"follows": "thread"`. Read `context()` in `init` and loop on `onContextChanged()`. `openPanel` and `kg surface open` / `close` / `list` are the same path.
