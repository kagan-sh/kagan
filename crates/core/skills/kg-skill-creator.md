---
name: kg-skill-creator
description: Write and test a kagan skill.
---

Read `kg guide skills`. Run `kg skill new <name>` (or --project). Use a lowercase hyphenated folder name and matching YAML name plus a short description in SKILL.md. Keep instructions focused on the task. Put supporting files in the folder. Verify with `kg skill list`, `kg skill show <name>` and `kg skill files <name>`. Ask the agent to load the skill with skill_load and try the task.
