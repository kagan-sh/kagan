# plugins: rules for changes here

Read the root `AGENTS.md` first. These rules add to it. `docs/plugin-api.md` describes the plugin API.

- A plugin sees only the areas its manifest asks for and the person approved. The module registry is that grant. Check: review.
- A power is granted only by the person, in the app. `kg ui` cannot approve one. Check: review.
- Removing a plugin and deleting a thread wait for the person's approval. Nothing is deleted until they approve. Check: review.
