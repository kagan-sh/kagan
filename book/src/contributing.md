# Contributing

The [GitHub repository](https://github.com/kagan-sh/kagan) has the source and the contributor rules in `AGENTS.md`.

The [design documents](https://github.com/kagan-sh/kagan/tree/main/docs) describe the architecture, decisions, plugin contract, and window design for contributors.

For a UI change, run `sh scripts/smoke.sh` on macOS. It starts an isolated window, snapshots it, saves a screenshot, and quits; `--keep` keeps the files.
