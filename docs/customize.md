Each change below is in the person's data folder (the `dataDir` in `kg status --json`), or is a command.

Themes: a theme is a JSON file at `<dataDir>/themes/<id>.json` with a `name`, a complete `light` palette, a complete `dark` palette, and optionally `look`. `kg theme new <id> [--from <theme>]` writes a copy there, `kg theme folder` prints the folder, and `kg theme set <id> <light|dark|system>` picks a theme and a mode. `fjord` is the default; `ember` and `grey` ship too. A plugin theme's id is `<plugin id>/<theme id>`.

Keys: `kg keymap get` lists them. `kg keymap set <action> <key>` rebinds one. To restore the default, run `kg keymap set <action> "" --reset`. The action is a name such as `ToggleSidebar`, or `<plugin id>:<command>` for a plugin command.

Preferences: `kg preference get <key>` reads one, and `kg preference set <key> <value>` saves one, for example `kg preference set notify off`. Keys: `confirm-archive`, `agent-integration`, `notify`, `usage-limits`, `plugin-status`, `update-check`, `branch-prefix`, `density`, `font-ui`, `font-terminal`, `terminal-copy-on-select`, `terminal-links-browser`, `setup-guide`, `sidebar-order`, `sidebar-hide-empty-projects`, `sidebar-unread-first`, `terminal-font-size`, `review-viewed`, `rail-hidden`, `<window>.left-sidebar`, `<window>.left-width`, `<window>.right-sidebar`, `<window>.right-width`, `<window>.review-wrap`, `slot.threads`, and `slot.review`. `update-check` is off by default; when it is on, kagan checks at launch and daily. `usage-limits` is on when unset: it shows the Claude and Codex limits in the sidebar footer, asking the Claude Code and Codex installed on this computer. `false` hides the footer and clears the readings [decision 272]. `branch-prefix` goes in front of the branch names kagan makes, such as `bb/`; it must be empty or a valid git branch start. `density` is `compact`, `default` or `roomy`, and scales the spacing. `font-ui` and `font-terminal` name a font family; empty, or a name the system does not have, uses Inter and JetBrains Mono. `terminal-copy-on-select` copies a selection when you let go of the mouse. It is on when unset, and `false` leaves the clipboard alone. `terminal-links-browser` opens a clicked terminal link in the Browser tab instead of the system browser. The `slot.*` values are a plugin id, or `kagan` for the built-in; set them from the window, or with `kg plugin use`. `sidebar-order` is `current` or `attention`; `attention` orders the threads in a project by attention, newest first, and pinned threads stay first. `sidebar-hide-empty-projects` hides a project that has no visible thread, except the chosen project and the project whose page is open. `sidebar-unread-first` puts unread threads after the pinned ones. Unset, the list stays as it is. `rail-hidden` is a list of plugin ids whose rail icons are hidden; use `kg plugin rail <id> hide` or `show` rather than writing it by hand, and the list is cleared when the plugin is removed.

Agent rules: `kg instructions get`, `kg instructions set <text>` (or `set --file <path>`, or `set --file -` for stdin), and `kg instructions clear` edit the global rules in `<dataDir>/instructions.md`. Add `--project <id>` to edit one project's rules in `<project>/.kagan/instructions.md`. Each file holds at most 16 KiB (16,384 bytes), and `set` refuses more. When agent integration is on, a start adds the global rules after the line `Instructions from your kagan instructions file:`, then the project's after `Instructions from this project's kagan instructions file:`, so a thread sees up to 32 KiB. The rules reach `claude`, `codex`, `cursor-agent` and `pi`. `kimi` and `opencode` do not get them. Settings → General → Agent rules edits the same files.

Skills: `kg skill new <name>` writes into `<dataDir>/skills`, and `--project` writes into `<project>/.kagan/skills`. `kg skill list` shows what loads and any error.
