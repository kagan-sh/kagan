Agent marks for the program picker. `picker/mark.rs` maps each command to its file here.

- claude.svg, gemini.svg, codex.svg, cursor.svg, kimi.svg, opencode.svg: Simple Icons (https://simpleicons.org), CC0 1.0. Each is a trademark of its owner, used only to name that program.
  - cursor.svg, for cursor-agent: the source Simple Icons lists is https://cursor.com/brand. This is the page I took the mark from; I did not read its terms, so check them before a release.
  - kimi.svg, for kimi: the source Simple Icons lists is https://moonshotai.github.io/Branding-Guide. Same caveat; this is the brand guide I took the mark from.
- copilot.svg: the GitHub Copilot mark from Primer Octicons, taken through Simple Icons, which lists it as MIT. Licence text: Primer-MIT.txt, copied unchanged from https://github.com/primer/octicons (LICENSE, 2026 GitHub Inc.).
